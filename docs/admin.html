가격표 관리

GitHub 저장소 수정 권한이 있는 관리자만 가격표를 변경할 수 있습니다. 아래 버튼을 누르면 GitHub 로그인 및 파일 업로드 화면으로 이동합니다.

  1. 전체 상품이 담긴 새 엑셀의 파일 이름을 price-list.xlsx로 바꿔 주세요.
  2. 엑셀 업로드를 눌러 파일을 끌어놓거나 choose your files로 선택하세요. 기존 파일도 같은 이름으로 교체합니다.
  3. 화면 아래 Commit changes를 눌러 저장하세요. 브랜치 선택이 나오면 main에 직접 저장을 선택하세요.
  4. 업데이트 진행 확인에서 가장 최근 작업이 녹색 체크가 되면 반영 완료입니다. 보통 수 분이 걸립니다. 가격 검색 화면을 새로고침하세요.

업로드 전 확인

업로드한 파일로 전체 가격표가 교체됩니다. 파일에 없는 상품은 검색에서 제외됩니다. 이 저장소는 공개이므로 업로드한 원본 엑셀도 공개됩니다. 공개할 가격표만 넣어 주세요.

필수 열: 품명, 규격, 품목대분류, 품목중분류, 표준단가, 기준단위
선택 열: 평량, 패턴, 적재환산량, 추가특성(인증), 색상코드
최대 10MB / 20,000개 상품 · 수식은 값으로 붙여넣은 뒤 저장

오류가 있으면 기존 공개 가격표가 유지됩니다. 진행 확인 화면의 실패한 작업에서 오류를 확인하고 파일을 수정해 다시 업로드하세요. 매 단위의 500매 환산, 유포 결 반전과 화이트크라프트 80g 250매포의 포 단위 보정은 유지됩니다.
